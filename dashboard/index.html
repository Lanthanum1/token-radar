240 protocols that record no token, ranked by what a launch would be worth — each with a concrete farm plan, its cost and its time. Implied values are this radar’s own claim, computed from the snapshot alone; they are not a prediction that a token will launch, or when.

How the implied value is worked out

implied value = TVL × category multiple × growth × maturity × chains × tier

  • Category multiple — the median market-cap / TVL of the protocols in that category whose token already trades, computed from this snapshot (overall median ). No name is ever special-cased.
  • Growth — 1 + 7-day TVL change (clamped −50% to +100%) × 0.6.
  • Maturity — 0.75 to 1.20 by days tracked with no token (up to 3 years; unknown age counts as 365 days).
  • Chains — +3% per extra chain, up to +15%. Tier — ×1.0 for rule-clean rows, ×0.5 for rows the watchlist rule excludes (wrapped, staked, bridged or versioned products), which are flagged, never hidden.
